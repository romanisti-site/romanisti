# RC14 Changelog

## Removed

- Fifteen separate Observation hotspots.
- Hidden discovery-based interaction.
- Hover-only title tooltips.

## Added

- Five permanent brass object halos with concise labels.
- A primary Observations halo on the front central book.
- Persistent desktop hover/focus panel behavior.
- Tap-to-open mobile bottom sheet behavior.
- Escape, outside-click, close-button, and keyboard support.
- Up to ten large Observation cards showing category and title.
- Live Special Editions and Future Projects landing routes.

## Preserved

- Locked Works Room plate.
- Shared 8:5 image/overlay coordinate canvas.
- Existing Observation Archive and Codex I routes.

## RC14.1 — Architectural Calibration

- Recentered and enlarged the Codex I halo to coincide with the carved circular wall medallion.
- Moved and tightened Special Editions around the left glass display case.
- Tightened Observation Archive around the right glass display case for symmetry.
- Reanchored Future Projects to the closed front-left portfolio, an object that more clearly suggests unfinished work.
- Reduced idle halo opacity, fill, and shadow so the annotations remain legible without competing with the room.
- Preserved the stronger hover, focus, and active states for clear interaction feedback.


## RC14.2 — Codex Medallion Calibration

- Shifted the Codex I halo right and slightly down.
- Reduced its diameter so the line sits just inside the existing carved stone circle.
- Preserved the Codex label and all other RC14.1 behavior unchanged.


## RC14.3 — Codex Square Calibration

- Replaced the circular Codex I halo with a square object annotation.
- Centered the square around the Capitoline Wolf relief rather than the carved medallion.
- Shifted the Codex label a few pixels right by aligning it to the square’s new center.
- Preserved all other Works Room navigation and Observation-panel behavior unchanged.
