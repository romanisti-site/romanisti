# Romanisti Reading Room RC2 — Sprint B

This release is the first visible browser assembly using the certified architectural library.

## Run locally

```bash
npm install
npm run dev
```

Open the local address Astro prints, normally `http://localhost:4321`.

## Build

```bash
npm run build
npm run preview
```

## Included

- Astro repository
- Canonical asset manifest
- 001 Librarian's Table
- 002 Bronze Reading Stand
- 003 The Liber
- 004 Julius Caesar Bust
- 005 Wall System material
- 006 Floor System material
- 007 Reading Room Aperture
- 008 Roman Light Studies reference
- Responsive CSS assembly
- Desktop and mobile room compositions

The certified objects are reused as image assets. They are not regenerated by the application.
